# EXPERIMENTAL — forced-span probe. Not production data.

Nothing in this directory may be read by production analysis. The production
discourse results come only from `../discopy_explicit_candidates.csv` filtered
to `is_connective == True`.

## What this is

`forced_span_probe.py` bypasses **only** `get_connective_candidates()` and pushes
DiMLex spans discopy never enumerated through the unchanged classifier: same
weights, same `get_bert_features`, same `used_context`, same argmax, full
document embedded. Every target was asserted to be genuinely `NOT_A_CANDIDATE`,
so the probe is not circular.

It answers one question: *if the candidate inventory were widened, what would
the existing classifier do?*

## Result

1,659 forced spans → 253 accepted (15.3%). `eventually` 98.2% accepted (56 of
the 253 added relations) at mean confidence 0.976 — and 0/5 of those judged
valid by hand. Confidence is **inverted** for out-of-inventory spans (accepted
0.620 vs NoSense 0.943), a signature of out-of-distribution behaviour.
