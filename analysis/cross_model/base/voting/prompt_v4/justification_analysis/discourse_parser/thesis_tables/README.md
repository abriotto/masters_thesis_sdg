# Thesis tables

**The final thesis tables are in `final_discourse/`. Everything in this
directory's root is diagnostic or superseded** — see `../ARTIFACT_STATUS.md` for
the full classification.

## `final_discourse/` — PRODUCTION

Standard discopy only, from `discopy_explicit_candidates.csv` filtered to
`is_connective == True`. Generated by
`notebooks/04_justification_analysis/7_final_discourse_analysis.ipynb`.

| table | what |
|---|---|
| `F0_run_level` | per-run counts, words and densities — the base for everything below |
| `F1_overall_density` | overall explicit-relation density (per 100 words, per justification, % of justifications with ≥1) |
| `F2_top_level_density` | Comparison / Contingency / Expansion / Temporal per 100 words → **fig F1** |
| `F3_top_level_composition` | relative four-class composition → **fig F2** |
| `F4_fine_grained_senses` | level-2 PDTB senses, secondary → **fig F3** |
| `F5_bootstrap_pairwise` | paired game-level bootstrap, 95% percentile CIs for pairwise model differences |

Figures: `../figures/final_discourse/` — **F1** density, **F2** composition,
**F3** level-2 senses, **F4** bootstrap forest (stochastic, the main inferential
figure), **F5** bootstrap forest (greedy, separate).

Aggregation: each run computed independently, then mean ± SD across the **three
stochastic runs**; **greedy is one run, always separate**, SD undefined (NaN).
Word denominator is always `WORD_PATTERN` (169,748 tokens).

`F3` computes shares **within each run and then averages** — this is why it
differs slightly from the deprecated pooled table `05`.

`F5` resamples the **191 games** with replacement, uses the **same** resampled
ids for every model, keeps all three stochastic realisations of a sampled game,
averages the three run-level rates into one model value per replicate, and takes
percentile intervals of the pairwise differences. 10,000 replicates, seed
20260826. Stochastic and greedy bootstrapped separately. No p-values.

`Expansion.Restatement` has **n = 1** corpus-wide. It stays in `F4` — dropping it
would change the share denominator — and appears as a near-invisible bar in
fig F3, which is the honest rendering of a singleton.
