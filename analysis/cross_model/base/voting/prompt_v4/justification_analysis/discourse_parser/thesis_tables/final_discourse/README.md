# FINAL discourse tables — canonical thesis results

Standard discopy, explicit relations only. Derived solely from
`../../discopy_explicit_candidates.csv` filtered to `is_connective == True`.

Generated by **`notebooks/04_justification_analysis/7_final_discourse_analysis.ipynb`**.
Nothing else writes here, and no DiMLex, forced-span or hybrid artifact may enter.

| table | what |
|---|---|
| `F0_run_level` | per-run counts, words and densities — the base for everything below |
| `F1_overall_density` | overall explicit-relation density |
| `F2_top_level_density` | Comparison / Contingency / Expansion / Temporal per 100 words |
| `F3_top_level_composition` | relative four-class composition |
| `F4_fine_grained_senses` | level-2 PDTB senses (secondary) |
| `F5_bootstrap_pairwise` | paired game-level bootstrap, 95% percentile CIs |

Aggregation: per run first, then mean ± SD across the three stochastic runs;
greedy is a single run, kept separate, SD undefined (NaN). Word denominator is
`WORD_PATTERN`, 169,748 tokens.

Bootstrap: 191 games resampled with replacement, the same ids for every model,
all three stochastic realisations of a sampled game retained, per-run rates
averaged into one model value per replicate. 10,000 replicates, seed 20260826.
Stochastic and greedy bootstrapped separately. No p-values.

Figures: `../../figures/final_discourse/`.
Everything in the parent `thesis_tables/` directory is diagnostic or superseded
— see `../../ARTIFACT_STATUS.md`.
